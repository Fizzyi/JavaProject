htmall-nginx 前端项目 mac 启动方式
1. 安装 nginx
2. 修改 conf/nginx.conf 文件
```shell
# 1、查看用户组 
dscl . -list /Groups
# 2、查看指定用户组的详细信息 我用的是 admin，在GroupMembership中查看 username
dscl . -read /Groups/<groupName>
# 3、在 nginx.conf中添加 ;
user <username> <groupName>
```
3. 启动 nginx
```
sudo nginx -c conf/nginx.conf
```
